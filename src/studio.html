Story Studio

A local-only workbench for story files. Load a story folder, edit JSON, validate it, download the edited file, and open a phone preview. The browser cannot write changes back into your source folder.

Story authoring guide

1. Load story files

Choose the src/story/ folder in a browser that supports folder selection, or begin with the bundled sample. Files stay in this browser tab.

For the folder picker, select src/story itself so character, location and asset paths remain intact.

2. Edit a JSON or theme file

Edits are held in memory. Download this file and replace the matching path in your story folder.

3. Validate

Load story files to see validation results.

    Route outline

    A structural view of choices, conditions, branches, quizzes and endings. It does not replace playing every route.

    4. Preview

    Preview opens in another tab and uses a separate save namespace, so it cannot overwrite normal game progress. Keep this Studio tab open while previewing imported local assets.
