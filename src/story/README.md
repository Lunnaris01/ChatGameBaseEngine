# Story files

This folder contains only editable story content: character JSON, location JSON,
local assets, `story.json`, and `theme.css`.

For the complete story-only authoring guide, including every step type and
examples, see [`../../STORY_GUIDE.md`](../../STORY_GUIDE.md). For editing and
previewing files in the browser, run `bun run dev` and open
`http://localhost:8080/studio.html`.

The reusable Tutorial and Mai's five-chapter romance ministory are included as
examples. The Tutorial unlocks Mai. Keep the Tutorial; rewrite Mai and replace
the sample art when adapting this starter for a new narrative. If Mai is
replaced, update the Tutorial's `unlock` step to target your first character.
